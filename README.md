# 남양주 하루 여행 추천 (travel-recommender)

날짜를 입력하면 **경기도 남양주시 안의 읍/면/동 한 곳**을 추천하고, 그 지역의 맛집과 하루 일정을 담은 마크다운 리포트를 만들어 주는 Python CLI입니다.

## 개요

1. **Gemini**가 남양주시의 읍·면·동 한 곳과 방문할 장소의 정확한 이름을 추천합니다.
   - 지역은 `남양주시 OO읍/면/동` 형식인지 검사합니다.
   - JSON 파싱·검증 실패 시 1회 다시 요청합니다.
   - HTTP 429·500·502·503·504 및 타임아웃은 호출당 최초 요청 포함 **최대 3회** 시도합니다(1초, 2초 대기). 그 외 오류는 즉시 종료합니다.
2. **카카오 로컬 API**에서 추천 장소의 이름과 주소를 확인하고 음식점도 검색합니다.
   - 추천 장소는 카카오 결과의 이름이 정확히 일치해야 합니다. 활동 설명 등 이름을 확인할 수 없는 항목은 제외합니다.
   - 지번 주소를 우선 사용하고, 없으면 도로명 주소를 사용합니다. 주소의 시 및 바로 다음 읍·면·동 토큰이 선택 지역과 일치해야 합니다.
   - 지역 밖, 주소 누락, 동 확인 불가, 검색 실패, 이름 불일치 항목은 제외하고 `errors`에 대상과 이유를 기록합니다.
   - 검증된 음식점 중 음식 종류가 겹치지 않게 최대 5곳을 선택합니다.
3. **검증된 목록으로 리포트와 일정을 직접 구성**합니다.
   - Gemini의 자유 생성 최종 리포트는 사용하지 않습니다. 미검증 추천 이유와 행사 문구도 노출하지 않습니다.
   - 검증된 장소가 없으면 데이터 없음으로 표시합니다. 카페·디저트는 식사 일정에 사용하지 않습니다.
   - 날씨는 실시간 예보가 아닌 Gemini의 계절 경향 설명입니다.

## 실행 방법

Python 3.9 이상이 필요합니다.

```bash
# 1) 가상환경 만들기 및 의존성 설치
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt

# 2) 키 설정 (아래 '키 설정' 참고)

# 3) 실행
.venv/bin/python main.py -date "2026-10-20"
```

- `-date`는 필수이며 `YYYY-MM-DD` 형식이어야 합니다. 자리 수가 틀리거나 실제 존재하지 않는 날짜이면 usage를 출력하고 종료합니다.
- 키가 없으면 설정 방법을 안내하고 바로 종료합니다.

### Gemini 모델 바꾸기

기본 모델은 `gemini-2.5-flash`이며 환경변수 `GEMINI_MODEL`로 바꿀 수 있습니다.

```bash
GEMINI_MODEL=gemini-2.5-pro .venv/bin/python main.py -date "2026-10-20"
```

> **HTTP 404가 나오면 `GEMINI_MODEL`을 바꿔보세요.** 모델 이름이 바뀌었거나 더 이상 제공되지 않는 경우입니다.

## 키 설정

필요한 키는 두 가지입니다.

| 환경변수 | 발급처 |
| --- | --- |
| `GEMINI_API_KEY` | Google AI Studio |
| `KAKAO_REST_API_KEY` | Kakao Developers → 내 애플리케이션 → REST API 키 |

**방법 1 — `.env` 파일**

```bash
cp .env.example .env
# 편집기로 .env 를 열어 값을 채우세요.
```

**방법 2 — 터미널 환경변수**

```bash
export GEMINI_API_KEY="발급받은_키"
export KAKAO_REST_API_KEY="발급받은_키"
```

둘 다 설정되어 있으면 터미널 환경변수가 우선합니다.

## 결과 확인 방법

실행하면 진행 로그와 저장 경로가 출력되고, `results/` 폴더에 두 파일이 생깁니다.

- `results/{날짜}_{실행시각}_{고유ID}_raw.json` — `recommendation`, `restaurants`, `errors` 원본 데이터
- `results/{날짜}_{실행시각}_{고유ID}_report.md` — 최종 리포트

파일은 고유 ID와 배타적 생성 모드로 저장해 기존 결과를 덮어쓰지 않습니다.

`errors`에는 단계(`stage`), 제외 대상(`place`), 제외 이유 또는 HTTP 상태 코드가 기록됩니다. API 응답 본문은 저장하지 않습니다.

## 오프라인 테스트

`requests`를 mock 하므로 키와 네트워크 없이 실행됩니다. 실제 API는 호출하지 않습니다.

```bash
.venv/bin/python -m unittest discover -s tests -v
```

맛집 0건, 카카오 HTTP 오류/네트워크 오류, Gemini JSON 파싱 실패 후 재시도 성공/실패, Gemini HTTP 404, 키 누락 시 종료, 잘못된 날짜 형식, 결과·로그에 키가 남지 않는지 등을 검사합니다.

## 키 유출 주의사항

- `.env`는 `.gitignore`에 들어 있습니다. **절대 커밋하지 마세요.** `git add` 전에 `git status`로 확인하세요.
- 키는 URL에 넣지 않고 헤더(`x-goog-api-key`, `Authorization: KakaoAK ...`)로만 보냅니다.
- 로그, 결과 파일, 오류 메시지에는 키를 남기지 않습니다. 오류는 HTTP 상태 코드(또는 예외 종류)만 기록합니다.
- 키를 채팅, 이슈, 스크린샷에 붙여넣지 마세요. 노출됐다면 즉시 발급처에서 키를 폐기하고 재발급하세요.
- `.env.example`에는 값을 넣지 마세요.

## 한계

- **날씨는 실시간 예보가 아닙니다.** Gemini가 알려주는 계절 경향일 뿐이므로 여행 전에 기상청 예보를 확인하세요.
- 카카오에서 장소의 존재와 주소를 확인합니다. 행사 개최 여부·영업시간까지 확인하는 것은 아닙니다.
- **맛집은 평점 순이 아니라 카카오 키워드 검색 정확도 순**입니다. 맛이나 인기를 보장하지 않습니다.
- 행정동과 법정동 명칭이 다르거나 주소에 동이 없는 경우에는 보수적으로 제외될 수 있습니다.
